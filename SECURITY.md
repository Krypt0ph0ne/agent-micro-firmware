# Security policy

## Supported versions

Until the first stable release, only the latest commit on `main` receives
security fixes. After releases begin, this table will identify supported
versions.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting for this repository. If that
option is unavailable, contact the repository owner privately through the
contact method on their GitHub profile. Do not open a public issue before a
fix or coordinated disclosure date is agreed.

Include the affected commit, hardware revision, reproduction steps, impact,
and a suggested mitigation when possible. Remove device UIDs, DataFlash,
personal paths, tokens, and unrelated logs.

Expect an acknowledgement within seven days. The maintainers will validate,
coordinate a fix, credit the reporter if requested, and publish an advisory
when users can act safely. This project does not offer a bug bounty.
