# Release photo checklist

The first stable firmware release is blocked until the maintainers add their
own redistributable photos:

- `sinloon-sl2024502-sw2-orientation.jpg`: complete board, USB-C at the top,
  SW2 labeled clearly.
- `sinloon-sl2024502-sw2-bridge.jpg`: close-up showing a safe bridge across
  only the two SW2 pads.

Record photographer, date, hardware revision, and chosen CC license in this
file when adding the images. Do not use Amazon, seller, OpenAI, or Anthropic
assets.
